# MAN-PWA-001 — PWA Installation & Standalone Launch Procedure

## Procedure Steps
1. Open the production build (`npm run preview` or deployed URL) in a browser supporting PWA installation (e.g. Chrome / Edge).
2. Confirm installability via browser address bar or install prompt, and install.
3. Launch the application from the installed desktop/OS icon.
4. Sign in and complete one study card.
5. Repeat ordinary browser navigation in a secondary browser window.

## Acceptance Criteria
- Installed launch operates in standalone presentation mode without browser URL chrome.
- Ordinary URL browser operation remains fully functional simultaneously.
