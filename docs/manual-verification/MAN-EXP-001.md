# MAN-EXP-001 — Exploratory Testing Procedure

## Procedure Steps
Perform a minimum of 30 minutes of unstructured exploratory verification covering:
1. Rapid clicking and double-submitting forms/buttons.
2. Browser history navigation (Back / Forward).
3. Concurrent multi-tab operations under the same authenticated account.
4. Extremely long Unicode text, emoji, and formatting boundaries in flashcard text.
5. Responsive layout resizing across very narrow (320px) and wide (4K) windows.
6. Deliberate network disconnections during active study sessions.
7. Session timeout and re-authentication handling.

## Acceptance Criteria
- No unhandled JavaScript runtime exceptions or white screens.
- Application gracefully surfaces error banners and allows retry.
- Data integrity maintained across sessions and tabs.
