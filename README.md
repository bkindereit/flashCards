# FlashCards

An interactive flashcard application designed for active recall and spaced repetition learning.

## Features

- 🗂️ **Deck Management**: Organize cards into custom decks by subject or topic.
- 🔄 **Active Recall & Spaced Repetition**: Maximize retention through proven learning techniques.
- 📊 **Progress Tracking**: Monitor your study sessions and retention stats over time.
- 🎯 **Clean, Focused UI**: Minimalist interface designed for distraction-free study.

## Getting Started

### Prerequisites

- Git
- Modern web browser / Node.js (or runtime of choice)

### Setup

```bash
git clone https://github.com/BastianKindereit/flashCards.git
cd flashCards
```
