# FlashCards - Antigravity Workspace Guidelines

Welcome to the **flashCards** Antigravity workspace.

## Project Overview
FlashCards is an interactive flashcard learning application tailored for active recall and spaced repetition.

## Workspace Architecture & Guidelines
- **Modularity**: Keep components and utilities modular and decoupled.
- **Testing**: Include unit and integration tests for new core functionality.
- **Documentation**: Maintain up-to-date documentation and code comments.
- **Git Conventions**: Use clear and descriptive commit messages following conventional commits format.
